## Cómo ejecutar

1. Instalar dependencias: `pip install -r requirements.txt`
2. Abrir `proyecto_final.ipynb` y ejecutar todo (Run All). El notebook debe estar en la misma carpeta que `cci/` y `datos/`.
3. Las figuras se guardan en `resultados/` y las tablas en `resultados/tablas/`.

## Estructura

- `proyecto_final.ipynb`: notebook principal, llama las funciones de cada parte en orden.
- `cci/`: código de cada parte (`parte_a.py` a `parte_g.py`), parámetros del grupo (`config.py`) y funciones de intervalos (`estadistica.py`).
- `datos/`: los tres archivos entregados por el docente para nuestro grupo.
